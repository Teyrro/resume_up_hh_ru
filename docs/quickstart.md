# Быстрый старт: запуск за 15 минут

Пошаговая инструкция для тех, кто раньше не запускал серверные программы.
Сервис поднимает **ваше** резюме на hh.ru, когда это разрешено (раз в 4 часа),
сам входит на hh.ru по коду из почты и пишет вам в Telegram.

Каждый запускает свою копию — на своём сервере или компьютере, со своими доступами.
Ваши пароли никуда, кроме вашей машины, не передаются.

## Что понадобится

| Что | Где взять | Время |
|---|---|---|
| Компьютер, который работает постоянно: VPS (от ~200 ₽/мес, 1 ГБ RAM) или домашний ПК/мини-ПК с Linux | любой хостинг VPS с Ubuntu 22.04/24.04 | — |
| Аккаунт соискателя на hh.ru с входом **по почте** | hh.ru | — |
| Gmail и пароль приложения для неё | шаг 1 ниже | 3 мин |
| Telegram-бот (необязательно, но удобно) | шаг 2 ниже | 2 мин |

> Windows: подойдёт WSL2 (Ubuntu) + Docker Desktop, но компьютер должен быть включён,
> иначе поднятий не будет. Надёжнее — недорогой VPS.

## Шаг 1. Пароль приложения Gmail

Сервис читает письмо с кодом входа от hh.ru. Обычный пароль Gmail для этого не подходит —
нужен отдельный **пароль приложения**.

1. Включите двухэтапную аутентификацию: https://myaccount.google.com/security
2. Откройте https://myaccount.google.com/apppasswords, введите название `hh-autoraise`,
   нажмите «Создать».
3. Скопируйте 16 букв (`abcd efgh ijkl mnop`) — понадобятся в шаге 3.

Подробно и что делать, если страницы нет: [gmail-setup.md](gmail-setup.md).
Яндекс и Mail.ru тоже подходят — мастер настройки сам подставит сервер почты.

## Шаг 2. Telegram-бот (необязательно)

1. Откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`.
2. Придумайте имя и username бота (должен заканчиваться на `bot`).
3. Скопируйте токен вида `123456789:AAH...` — понадобится в шаге 3.

`chat_id` искать не нужно — мастер настройки найдёт его сам.

## Шаг 3. Установка

Подключитесь к серверу (`ssh root@IP-сервера`) и выполните одну команду:

```bash
curl -fsSL https://raw.githubusercontent.com/Teyrro/resume_up_hh_ru/master/install.sh | bash
```

Мастер настройки:

1. проверит Docker и, если его нет, предложит установить;
2. спросит email для hh.ru и ссылки на резюме (просто вставьте адрес из браузера);
3. спросит пароль приложения (ввод скрыт);
4. проверит токен бота и попросит написать боту — так он узнает ваш `chat_id`;
5. спросит часовой пояс (тот, в котором hh.ru показывает вам время);
6. скачает готовый образ, проверит почту и Telegram и запустит сервис.

Всё ставится в папку `~/hh-autoraise`. Если что-то ввели неверно — запустите мастер снова:

```bash
cd ~/hh-autoraise && ./setup.sh
```

## Шаг 4. Проверка

- В Telegram придёт «Проверка связи», затем «Сервис запущен» и «Выполнен повторный вход».
- Отправьте боту `/next` — он ответит, когда следующее поднятие.
- `/menu` — тихие часы (например, не поднимать ночью), режим уведомлений, журнал событий.

Без Telegram — смотрите логи:

```bash
cd ~/hh-autoraise && docker compose logs --tail 30
```

## Обслуживание

| Что сделать | Команда (в папке `~/hh-autoraise`) |
|---|---|
| Обновить до новой версии | `docker compose pull && docker compose up -d` |
| Посмотреть логи | `docker compose logs --tail 50` |
| Остановить | `docker compose down` |
| Запустить снова | `docker compose up -d` |
| Изменить настройки | `./setup.sh` |
| Снять стоп после капчи | `/resume` боту или `docker compose run --rm hh-autoraise resume` |

## Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| `IMAP: ОШИБКА … AUTHENTICATIONFAILED` | нужен пароль приложения, а не обычный — шаг 1 |
| `Telegram не принял токен` | скопируйте токен из @BotFather целиком |
| `Нет доступа к Docker` | `sudo usermod -aG docker $USER`, перелогиньтесь |
| «hh.ru показал капчу» | войдите на hh.ru вручную в браузере, подождите несколько часов, `/resume` |
| Другое | `/help` в боте, [README](../README.md#частые-проблемы), журнал: `/menu` → 📄 |

## Важно знать

- Правила hh.ru, вероятно, не разрешают автоматизацию — используете на свой риск.
  Сервис поднимает резюме не чаще, чем разрешает сам hh.ru, и не делает ничего другого.
- Один сервис — один аккаунт hh.ru. Не запускайте его за других людей с одного сервера.
- Пароль приложения даёт доступ к почте: храните файл `.env` только у себя
  (мастер создаёт его с правами «только владелец»).
